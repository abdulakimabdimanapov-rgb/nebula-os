# Nebula OS

This is my Web OS project created for the Stardance challenge! It combines a smooth macOS-style UI with powerful Linux-inspired terminal features.

## 🚀 Features
* **macOS UI:** Floating dock with magnification effect, glassmorphic windows, and top status bar.
* **Terminal (Nebula CLI):** Support for custom commands (`neofetch`, `matrix`, `theme`, `help`, etc.).
* **Built-in Apps:** File Explorer, Notes with localStorage save, Calculator, Web Browser, and Settings.
* **Themes:** Quick theme switcher (Dracula, Nord, Cyberpunk, Mac).

## 🛠️ How I built it
I used HTML, CSS, and Vanilla JavaScript. I designed the interface to feel like a real operating system and added interactive apps inside floating windows that you can drag and resize.

## 💻 How to test
1. Open the Demo link.
2. Try opening apps from the Dock.
3. Open the Terminal app and type `neofetch` or `matrix`!
