# ◐ Nebula OS — операционная система в браузере

Полноценная мини-ОС на **чистом HTML, CSS и JavaScript** — без единой внешней
библиотеки, фреймворка или CDN. Всё работает локально и офлайн.

![stack](https://img.shields.io/badge/stack-html%20%7C%20css%20%7C%20js-orange)

## 🚀 Запуск

Самый простой способ — открыть `index.html` двойным кликом.

Или поднять локальный сервер:

```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## ✨ Возможности

| Модуль | Описание |
|---|---|
| **Оконный менеджер** | Перетаскивание окон за шапку (нельзя «потерять» окно за краем), z-index фокус, кнопки «закрыть / свернуть / развернуть» (символы появляются при наведении), изменение размера за 8 ручек (края и углы), умное позиционирование без перекрытия (поиск свободного места по сетке + каскадный фолбэк), двойной клик по шапке — развернуть |
| **Меню «Пуск»** | Кнопка ◐ в доке: карточка пользователя, живая статистика (окна, тема, обои, аптайм, память), сетка приложений, «Перезагрузить ОС» |
| **Системный трей** | Wi-Fi (симуляция), громкость с попапом и тестом звука, полноэкранный режим, живые часы и дата |
| **Рабочий стол** | Иконки приложений: один клик — выделение, двойной — открытие (клавиатура: Enter/Space). Живой фон — canvas-частицы с параллаксом за курсором |
| **Звуки UI** | Web Audio API: короткие блипы на открытие/закрытие/клик, мастер-громкость и мьют (переживают перезагрузку) |
| **📝 Заметки** | Автосохранение в `localStorage`, заголовок, индикатор «Сохранено HH:MM:SS», очистка |
| **📁 Файлы** | Виртуальная файловая система в `localStorage`: папки и файлы, хлебные крошки, навигация (назад / вперёд / вверх), переименование, удаление, скачивание, встроенный текстовый редактор (Ctrl+S), виды «сетка / список» |
| **💻 Терминал** | Команды: `help`, `clear`, `date`, `echo`, `theme [dark\|neon\|cyberpunk]`, `matrix`, `ls [путь]`, `cat`, `mkdir`, `touch`, `rm`, `open`, `whoami`, `neofetch`, `about`. История команд (стрелки ↑/↓) |
| **🧮 Калькулятор** | Базовые операции, `%`, `±`, работа с клавиатуры |
| **🌐 Браузер** | Вкладки, адресная строка с распознаванием поисковых запросов (DuckDuckGo), закладки и история в `localStorage`, стартовая страница с быстрыми ссылками и избранными приложениями, кнопки «назад/вперёд/обновить/домой», горячие клавиши Ctrl+L/T/W, тёмная тема страниц (инверсия цветов в iframe), внутренние страницы `nebula://home`, `nebula://apps` (лаунчер приложений с поиском, категориями, избранным и клавиатурной навигацией: стрелки, Home/End, Enter; категория и поиск запоминаются между визитами), `nebula://bookmarks`, `nebula://history` и просмотр файловой системы `nebula://vfs/путь` (листинг папок, хлебные крошки, чтение и скачивание файлов, страница 404) |
| **🎵 Музыка** | Процедурный lo-fi генератор на Web Audio API — ни одного аудиофайла: бас, пэд-аккорды и пентатоническая мелодия синтезируются в реальном времени. Плейлист, эквалайзер, прогресс |
| **📅 Календарь** | Месячная сетка, подсветка сегодняшнего дня, события с временем в `localStorage`, добавление/удаление |
| **🎨 Настройки** | Переключение 3 тем (Ночь / Неон / Киберпанк) и 4 обоев, сброс настроек |
| **Контекстное меню** | ПКМ на рабочем столе: быстрый запуск приложений, смена обоев, перезагрузка |

## 🎨 Дизайн

- Glassmorphism: полупрозрачное стекло, `backdrop-filter: blur`, мягкие тени
- Анимированный градиентный фон («живые» размытые пятна) + canvas-частицы с параллаксом
- Плавные анимации появления окон, дока, hover-эффекты с упругим откликом, звуковая обратная связь
- Экран загрузки ОС при старте (пропускается кликом), перезагрузка через «Пуск»
- Собственный стиль — осознанная альтернатива Windows/macOS

## 🗂 Структура

```
webos/
├── index.html   — разметка рабочего стола (Пуск, трей, окна)
├── style.css    — темы, обои, glassmorphism, анимации, приложения
└── script.js    — менеджер окон, док, трей, Пуск, приложения (модульно, с комментариями)
```

## 💾 Состояние

Настройки и данные сохраняются в `localStorage` и переживают перезагрузку:

- `nebula.theme` / `nebula.wallpaper` — оформление
- `nebula.volume` / `nebula.muted` — звук
- `nebula.notes` — содержимое заметки
- `nebula.events` — события календаря
- `nebula.browserBookmarks` / `nebula.browserHistory` — закладки и история браузера
- `nebula.browserDark` — тёмная тема страниц браузера
- `nebula.browserFavApps` — избранные приложения браузера
- `nebula.browserAppsCat` / `nebula.browserAppsQ` — выбранная категория и поиск в лаунчере
- `nebula.fs` — виртуальная файловая система
- `nebula.filesCwd` / `nebula.filesView` — последний каталог и вид приложения «Файлы`
- `nebula.notifs` — история уведомлений
